# Backend do primeiro bimestre

Esta pasta preserva o protótipo Flask/MQTT e seus arquivos estáticos para permitir a comparação com a evolução do projeto. **Não faz parte da execução atual pelo Docker Compose.**

A aplicação avaliada no segundo bimestre usa `backend/api/` (FastAPI), `backend/services/` (simulador, mensageria e IA) e `frontend/` (Vue/Three.js). As dependências atuais estão em `backend/requirements.txt`; o arquivo `requirements.txt` desta pasta pertence somente ao protótipo antigo.

O firmware original permanece em `iot/wokwi/`. Não é necessário instalar Flask, PlatformIO ou Wokwi para testar a versão atual.
